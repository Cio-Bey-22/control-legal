Privacy Policy - CONTROL

CONTROL processes only the minimum data required to provide bot functionality.

  • Data may include server IDs, channel IDs, role IDs, user IDs, command usage, moderation/log events, and ticket metadata.
  • Message content is processed only when necessary for moderation or command handling.
  • Data is used solely for bot operation, security, abuse prevention, and troubleshooting.
  • We do not sell personal data.
  • Data may be stored temporarily or persistently as needed for features.
  • Server admins or users may request data deletion where applicable.
  • Discord and third-party services may process data under their own privacy policies.
  • AI features: when you use the /ai commands, or when a premium server has turned on the ticket AI assistant, the text needed for the answer (your command input, or the messages written in that support ticket together with the server's knowledge base) is sent to an AI provider, Groq, with Google Gemini as a backup, to generate a reply. CONTROL does not use this text for anything else. Server admins can turn the ticket assistant off at any time.
  • Error reports: if something breaks in the bot or on the website, technical details about the error (such as the page address and browser type) may be sent to the bot owners' private monitoring channel so the problem can be fixed.

Contact: Discord support server
